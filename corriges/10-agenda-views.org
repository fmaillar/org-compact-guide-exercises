* Exemple minimal autonome
Le fragment suivant illustre la syntaxe utile, sans prétendre constituer
l’unique solution ni modifier automatiquement les ateliers.

#+BEGIN_EXAMPLE
#+TODO: TODO WAIT | DONE
* TODO [#A] Calibrer :travail:urgent:
SCHEDULED: <2027-02-03 Wed>
:PROPERTIES:
:Responsable: Ada
:END:

# Recherche : travail|maison+urgent
# Depuis l’agenda : t, S-LEFT/RIGHT, l, g, C-c C-w
#+END_EXAMPLE
