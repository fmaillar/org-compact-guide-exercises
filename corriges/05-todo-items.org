* Exemple minimal autonome
Le fragment suivant illustre la syntaxe utile, sans prétendre constituer
l’unique solution ni modifier automatiquement les ateliers.

#+BEGIN_EXAMPLE
#+TODO: TODO(t) WAIT(w@) REVIEW(r) | DONE(d!) CANCELED(c@)
* TODO [#A] Préparer une campagne [50%]
** DONE Vérifier la sécurité
** DONE Vérifier le protocole
** TODO Vérifier le capteur
** TODO Valider le montage
* TODO Liste du jour [1/2]
- [X] Préparer le cahier
- [ ] Vérifier les câbles
#+END_EXAMPLE
