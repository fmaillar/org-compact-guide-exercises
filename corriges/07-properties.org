** 7 — Propriétés et valeurs permises
Commande(s) de référence : =:PROPERTIES: ; :END: ; _ALL ; #+PROPERTY ; C-c C-x p ; C-c C-c d=

*** E07-01-A — Résultat attendu
- Critère :: Chaque propriété est dans un drawer PROPERTIES fermé par :END:.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E07-01-B — Résultat attendu
- Critère :: Les valeurs permises sont héritées, mais la propriété ordinaire ne devient pas automatiquement définie.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E07-01-C — Résultat attendu
- Critère :: Le périmètre du réglage est explicite ; C-c C-x p sait mettre à jour la propriété.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E07-01-D — Résultat attendu
- Critère :: C-c C-c d retire la propriété voulue ; les recherches ne sélectionnent plus la valeur retirée.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.
