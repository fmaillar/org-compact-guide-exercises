* Correction — chapitre 2
Énoncés : [[file:../exercices/02-document-structure.org][retour aux exercices]].
Les opérations interactives et horodatées ont plusieurs solutions valides ;
les critères ci-dessous sont des invariants, pas des captures fictives.

** 2.1 — Headlines
Commande(s) de référence : =étoiles en début de ligne ; CUSTOM_ID ; org-footnote-section=

*** E02-01-A — Résultat attendu
- Critère :: Une étoile, deux étoiles puis trois étoiles correspondent aux trois niveaux ; les notes restent sous les bonnes branches.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E02-01-B — Résultat attendu
- Critère :: Le sous-arbre spécial de notes de bas de page est ignoré lors de l’export ; conserver les notes métier sous un autre nom.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.
