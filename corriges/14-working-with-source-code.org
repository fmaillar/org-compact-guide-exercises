* Exemple minimal autonome
Le fragment suivant illustre la syntaxe utile, sans prétendre constituer
l’unique solution ni modifier automatiquement les ateliers.

#+BEGIN_EXAMPLE
#+NAME: carre
#+BEGIN_SRC emacs-lisp :var n=7 :results value :exports both
(* n n)
#+END_SRC
#+RESULTS: carre
: 49

#+BEGIN_SRC emacs-lisp :results output
(princ "bonjour")
#+END_SRC
#+RESULTS:
: bonjour

#+BEGIN_SRC python :eval never :tangle ../exports/calcul.py
def aire_disque(rayon: float) -> float:
    return 3.141592653589793 * rayon ** 2
#+END_SRC
#+END_EXAMPLE
