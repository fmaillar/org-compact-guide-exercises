les critères ci-dessous sont des invariants, pas des captures fictives.

** 8.2 — Creating Timestamps
Commande(s) de référence : =C-c . ; C-c ! ; S-LEFT/RIGHT ; S-UP/DOWN=

*** E08-02-A — Résultat attendu
- Critère :: La commande réédite l’horodatage situé au point au lieu d’en créer un doublon.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E08-02-B — Résultat attendu
- Critère :: L’intervalle garde sa durée lorsque l’heure de début est déplacée.

*** E08-02-C — Résultat attendu

- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

** 8.3 — Deadlines and Scheduling
Commande(s) de référence : =C-c C-d ; C-c C-s ; DEADLINE ; SCHEDULED=

*** E08-03-A — Résultat attendu
- Critère :: SCHEDULED et DEADLINE ne sont pas synonymes ; la première indique un travail prévu, la seconde une échéance.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E08-03-B — Résultat attendu
- Critère :: Le rendez-vous est un timestamp simple, contrairement à une action planifiée.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E08-03-C — Résultat attendu
- Critère :: Le répétiteur est sur le timestamp actif ; l’anticipation dépend de org-deadline-warning-days.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

** 8.4 — Clocking Work Time
Commande(s) de référence : =C-c C-x C-i/o/e/q/j ; agenda l=

*** E08-04-A — Résultat attendu

*** E08-04-B — Résultat attendu

*** E08-04-C — Résultat attendu
