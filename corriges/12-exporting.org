* Correction — chapitre 12
Énoncés : [[file:../exercices/12-exporting.org][retour aux exercices]].
Les opérations interactives et horodatées ont plusieurs solutions valides ;
les critères ci-dessous sont des invariants, pas des captures fictives.

** 12.1 — The Export Dispatcher
Commande(s) de référence : =C-c C-e ; région active ; export de buffer=

*** E12-01-A — Résultat attendu
- Critère :: Les formats sont ceux réellement disponibles dans la version Org installée.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E12-01-B — Résultat attendu
- Critère :: Le contenu exporté diffère selon la sélection ; aucun export destructeur n’écrase une source.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

** 12.2 — Export Settings
Commande(s) de référence : =#+TITLE ; #+AUTHOR ; #+DATE ; #+EMAIL ; #+LANGUAGE ; # dans le dispatcher=

*** E12-02-A — Résultat attendu
- Critère :: Le titre, l’auteur fictif, la langue et la date sont transmis au document généré.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E12-02-B — Résultat attendu
- Critère :: Une option par fichier est préférée à un changement global inutile.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

** 12.4 — Include Files
Commande(s) de référence : =#+INCLUDE: ; src ; example ; export ; C-c '=

*** E12-04-A — Résultat attendu
- Critère :: Le texte inclus apparaît une seule fois dans l’export.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E12-04-B — Résultat attendu

** 12.5 — Comment Lines
Commande(s) de référence : =# commentaire ; #+BEGIN_COMMENT ; COMMENT ; C-c ;=

*** E12-05-A — Résultat attendu
- Critère :: La remarque et le bloc sont absents du rendu.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E12-05-B — Résultat attendu
- Critère :: Le sous-arbre COMMENT est exclu, y compris ses descendants.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

** 12.6 — ASCII/UTF-8 Export

*** E12-06-A — Résultat attendu
- Critère :: Les deux fichiers .txt existent dans un répertoire d’essai et n’exposent pas les marqueurs Org.

*** E12-06-B — Résultat attendu
- Critère :: Le traitement des caractères non ASCII est identifié plutôt que supposé.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

** 12.7 — HTML Export
Commande(s) de référence : =C-c C-e h h ; h o ; @@html:...@@ ; #+HTML ; #+BEGIN_EXPORT html=

*** E12-07-A — Résultat attendu
- Critère :: Le document .html est valide et les entités < et > sont échappées dans le texte ordinaire.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E12-07-B — Résultat attendu
- Critère :: Le HTML brut n’apparaît que dans la sortie HTML, avec une provenance de confiance.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

** 12.8 — LaTeX Export
Commande(s) de référence : =C-c C-e l l ; l p ; l o ; #+LATEX_CLASS ; @@latex:...@@ ; #+LATEX ; #+BEGIN_EXPORT latex=

*** E12-08-A — Résultat attendu
- Critère :: Le fichier contient la classe attendue, les titres, les formules et une table des matières si activée.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E12-08-B — Résultat attendu
- Critère :: Le PDF est créé sans modifier le fichier .org ; sinon l’étape est documentée comme facultative.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E12-08-C — Résultat attendu
- Critère :: Le rendu LaTeX inclut les fragments bruts ; un autre backend n’est pas censé les interpréter.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

** 12.9 — iCalendar Export

*** E12-09-A — Résultat attendu

*** E12-09-B — Résultat attendu

- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.
