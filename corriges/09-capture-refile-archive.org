** 9.1 — Capture
Commande(s) de référence : =org-default-notes-file ; C-c c ; C-c C-c ; C-c C-k ; C-c C-w=

*** E09-01-A — Résultat attendu
- Critère :: Une note a été écrite dans ateliers/09-capture-refile-archive.org sans interrompre le flux.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E09-01-B — Résultat attendu
- Critère :: La note annulée n’est pas créée ; la note reclassée existe à la destination choisie.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E09-01-C — Résultat attendu
- Critère :: Les codes %?, %U, %i et %a sont reconnus ; distinguer date active et inactive.
- Contrôle :: Reprendre l’action et vérifier dans le buffer source et,
  si applicable, dans l’agenda ou le document exporté.

*** E09-02-C — Résultat attendu

** 9.3 — Archiving
