** 13 · Projet — Configuration d’un projet de publication
Raccourcis et notions : =org-publish-project-alist ; :base-directory ; :publishing-directory ; :publishing-function=

*** E13-01-A — Exercice pratique
- Consigne :: Configurer un projet HTML dont les deux fichiers source résident dans ateliers/site/.
- Validation :: Le répertoire d’entrée et celui de sortie sont différents ; aucune publication réseau.
- Suivi :: Cocher E13-01-A dans le fichier PROGRESSION.org.

*** E13-01-B — Exercice pratique
- Consigne :: Ajouter un second composant pour copier une feuille de style et une image, puis lier les deux projets.
- Validation :: Les ressources statiques sont accessibles depuis les pages exportées.
- Suivi :: Cocher E13-01-B dans le fichier PROGRESSION.org.

*** E13-01-C — Exercice pratique
- Consigne :: Expliquer comment le moteur de publication pourrait transférer le résultat sur un serveur, sans effectuer de mise en ligne dans cet atelier.
- Validation :: Une éventuelle publication réseau nécessiterait un choix et une configuration explicites de la cible.
- Suivi :: Cocher E13-01-C dans le fichier PROGRESSION.org.

*** E13-01-D — Exercice pratique
- Consigne :: Publier les deux pages puis vérifier la navigation relative entre elles.
- Validation :: Les deux liens fonctionnent depuis exports/site/ en dehors d’Emacs.
- Suivi :: Cocher E13-01-D dans le fichier PROGRESSION.org.

** 13 · Commandes — Publication incrémentale et forcée
Raccourcis et notions : =C-c C-e P x/p/f/a ; argument préfixe=

*** E13-02-A — Exercice pratique
- Consigne :: Comparer la publication d’un fichier, du projet courant et de tous les projets.
- Validation :: Le périmètre varie avec f, p et a/x ; les bons fichiers sont générés.
- Suivi :: Cocher E13-02-A dans le fichier PROGRESSION.org.

*** E13-02-B — Exercice pratique
- Consigne :: Modifier une seule source et relancer la publication incrémentale, puis forcer une recompilation.
- Validation :: Org utilise des informations de modification ; le forçage régénère même si rien n’a changé.
- Suivi :: Cocher E13-02-B dans le fichier PROGRESSION.org.
